Principles

Three things I won't trade away

  1. 01

    Trust is designed, not declared

    Every AI state, thinking, unsure, wrong, recovering, gets a deliberate design. A confident UI over an uncertain model is a lie users eventually catch.

  2. 02

    Ship the system, not the screen

    Tokens, components and spec files outlive any single mock-up. If an engineer or an agent can't rebuild it from the spec, it isn't done.

  3. 03

    Accessible by default

    WCAG 2.2 AA is the floor, checked in code, not a final-week audit. It is also the fastest way to make AI output readable by everyone.
